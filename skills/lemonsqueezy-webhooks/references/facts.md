## Signature

- **Signature header:** X-Signature
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/webhook-requests](https://docs.lemonsqueezy.com/help/webhooks/webhook-requests): "An X-Signature header containing the request signature."
- **Scheme:** HMAC-SHA256, lowercase hex digest (the page says HMAC hex digest; sha256 is shown in the Node example createHmac call)
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/signing-requests](https://docs.lemonsqueezy.com/help/webhooks/signing-requests): "Lemon Squeezy generates the hash using an HMAC hex digest"
- **Signed content:** The request payload (raw body) only; no timestamp or other fields are included
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/signing-requests](https://docs.lemonsqueezy.com/help/webhooks/signing-requests): "Lemon Squeezy will use the signing secret to generate a hash of the payload and send the hash in the X-Signature header of the request."
- **Header format:** The header value is the bare hex digest, no prefix and no key=value pairs; a single signature (the Node example compares the whole header value to the computed hex digest)
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/signing-requests](https://docs.lemonsqueezy.com/help/webhooks/signing-requests): "const signature = Buffer.from(request.get('X-Signature') || '', 'utf8');"
- **Where the secret comes from:** A signing secret you choose yourself when creating the webhook, usually a random string of 6 to 40 characters; it is not generated by Lemon Squeezy
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/signing-requests](https://docs.lemonsqueezy.com/help/webhooks/signing-requests): "The secret can be anything you want but is normally a random string between 6 and 40 characters in length."
- **Secret scope:** Per webhook (each webhook has its own callback URL, signing secret and event list)
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks](https://docs.lemonsqueezy.com/help/webhooks): "This is a secret (usually a random string) between 6 and 40 characters that will be used to sign each request."

## Pitfalls the provider warns about

- **1:** order_created is always sent alongside subscription_created
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/event-types](https://docs.lemonsqueezy.com/help/webhooks/event-types): "An order_created event will always be sent alongside a subscription_created event."
- **2:** subscription_payment_success is always sent alongside subscription_payment_recovered
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/event-types](https://docs.lemonsqueezy.com/help/webhooks/event-types): "A subscription_payment_success event will always be sent alongside a subscription_payment_recovered event."
- **3:** order_created is always sent alongside license_key_created (so one purchase delivers several events)
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/event-types](https://docs.lemonsqueezy.com/help/webhooks/event-types): "An order_created event will always be sent alongside a license_key_created event."
- **4:** subscription_updated fires on every subscription event after the initial payment, so granular subscription events are usually redundant if subscription_updated is handled
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/event-types](https://docs.lemonsqueezy.com/help/webhooks/event-types): "subscription_updated is fired at every event after the initial payment."
- **5:** Cancelled subscriptions enter a grace period and can be resumed before expiry
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/event-types](https://docs.lemonsqueezy.com/help/webhooks/event-types): "The subscription enters a “grace period” until the next billing date, when it will expire."
- **6:** custom_data appears in meta only on Order, Subscription and License key related events
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/webhook-requests](https://docs.lemonsqueezy.com/help/webhooks/webhook-requests): "for all Order, Subscription and License key related events."
- **7:** Only a 200 response counts as success; any other status (including other 2xx) triggers a retry
  Read 2026-10-20 from [docs.lemonsqueezy.com/help/webhooks/webhook-requests](https://docs.lemonsqueezy.com/help/webhooks/webhook-requests): "If the response status is anything else, the webhook will be retried up to three more times"
